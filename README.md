# sokoban-solver

[![owner](https://img.shields.io/badge/owner-MapleCity1314-blue)](https://github.com/MapleCity1314)
[![repo](https://img.shields.io/badge/repo-sokoban--solver-blue)](https://github.com/MapleCity1314/sokoban-solver)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)

This deterministic Node.js solver parses each Sokoban level, decomposes the hallway-connected board into independent rooms, and searches push states with deadlock pruning to produce push-optimal movement solutions.

## Run it

```sh
node main.ts
```
